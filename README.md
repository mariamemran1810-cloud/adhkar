# 🌷 أذكاري

### سكينة القلب في كل وقت

موقع أنيق للأذكار اليومية بألوان بناتية ناعمة — أذكار الصباح والمساء والنوم، مع سُبحة إلكترونية وعدّاد استغفار.

</div>

---

## ✨ المميزات

- 🌅 **أذكار الصباح** و 🌇 **أذكار المساء** مع شريط تقدّم لإنجازكِ.
- 🌜 **أذكار النوم** (سبحان الله، الحمد لله، الله أكبر…).
- 📿 **السُبحة الإلكترونية** بحلقة خرزات تُضيء مع كل تسبيبة، مع اختيار الذكر والهدف.
- 🤍 **عدّاد الاستغفار** مع حفظ تلقائي للمجموع.
- 🌙 **وضع ليلي** وتصميم متجاوب مع الجوال.

## 🗂️ الملفات

| الملف | الوصف |
|------|-------|
| `index.html` | هيكل الصفحة والأقسام |
| `style.css` | التصميم والألوان والحركات |
| `script.js` | الأذكار والعدّادات والسُبحة |

## 🚀 التشغيل محلياً

افتحي ملف `index.html` مباشرة في أي متصفح حديث.
